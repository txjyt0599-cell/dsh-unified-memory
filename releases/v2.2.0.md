# v2.2.0 — 2026-11-26

压缩回忆（compacted-recall）三阶段发布版：把「已压缩历史」从不可见变为可检索、可兜底、可自动召回。

## 新增

- **`memory_search` 的压缩范围**：新增 `scope: "compacted_current_session"`，只检索当前会话已提交压缩覆盖的历史；`query: "*"` 浏览，`query: "关键词"` 检索。
- **阶段 2 · L0 兜底**：L0 轮次统一走活跃分片 + `_archive/` 归档 + 旧目录枚举；以 `u.id` 为锚生成稳定 ID，保留 `source_message_ids`；与 engram 按未覆盖消息 ID 集合去重。`memory_get` 可直接读取 `l0round:` 卡片，不写入 hits 或磁盘。
- **阶段 3 · B 层自动召回**：新增 `<compacted-session-recall>` 注入块；按 append-only 会话事件流重建完整 `compactionId`，同一压缩严格一次；in-flight 防并发、失败回合可重试、重启不重复。

## 安全与兼容

- `inject-fingerprint` 改为单一标签注册表，覆盖 L0 / hot / pulse / ongoing / compacted-session-recall。
- `capture` 注入过滤与预算清洗登记 B 块，伪造闭合标签统一降级。
- 未配置时，未压缩会话完全不受影响；已压缩会话默认启用轻提示与 B 层自动召回（`compactedRecall.enabled: false` 可关）。

## 测试

- `selftest-compacted-recall.mjs`：**90/90** 通过（阶段 1 + 阶段 3 E2E）。
- `selftest-compacted-recall-p2p3.mjs`：**33/33** 通过（阶段 2/3 正反例）。
- 陌生人全量：**63 套全绿 / pass=11 fail=0**；安全审计阻断 0、数据泄露 0。

## 升级

覆盖 `lib/`、`client.js`、`cordis.patch.yml`，重启 DSH。未压缩会话不受影响；`compactedRecall` 默认开启，可通过 `config.compactedRecall.enabled: false` 关闭。
