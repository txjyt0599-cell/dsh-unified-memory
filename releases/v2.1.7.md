# v2.1.7 — 2026-11-19

记忆连续性（continuity）与注入去重更新。默认行为仍是 legacy topN；continuity 需显式开启，便于回滚。

## 新增

- **continuity 模式（可选）**：`hotCardMode: "continuity"` 时启用 C1 近期语义、C2 24h 会话摘要、C3 轮次与 pulse 补位；预算按 token + 字符双判据闭合，超限时回退 topN。
- 新增 `lib/prefetch-continuity.js`：候选选择、C2 预算淘汰、冻结 renderedIds、pulse 补位与一次渲染；C1/C2/C3/pulse/ongoing-thread 全量清洗与 refute 过滤。
- 新增 `lib/inject-fingerprint.js`：L0/hot/pulse/ongoing-thread 独立 SHA-256 指纹、增量剥离与跨轮合并；纯 `diary-nudge` 不再占注入核验席位。

## 修复

- `<ongoing-thread>` 移到 `<hot-memory>` 外层，可被独立识别与增量剥离，不再被父块正则吞掉。
- 同会话 `diary-nudge` 按日期 + sessionKey 去重（空 session 归 `anon`）；跨 apply / 热重载共享去重状态，`__resetMerge: true` 时同步清空。
- `contentTextOf()` 保留原始字符串/数组文本，避免 `JSON.stringify` 转义导致指纹误判。
- `restart-batch` 新增连续 pre-step 回归；新增 `selftest-nudge-e2e` 沙箱隔离测试。

## 升级

覆盖 `lib/`、`client.js`、`cordis.patch.yml`，重启 DSH。默认不启用 continuity；需要时在插件配置加 `hotCardMode: "continuity"`，否则维持 legacy topN。
