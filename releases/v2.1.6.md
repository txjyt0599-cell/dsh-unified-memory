# v2.1.6 — 2026-11-16

整理版，无运行时行为变更。

## 背景

前一版把功能做齐了，但仓库公开面还留着开发期痕迹：本机推送笔记、生产对齐报告、根目录 45 个测试脚本、缺少发布门禁。本版只整理工程与发布流程，不改插件运行行为。

## 兼容性

- Node.js 最低 **22.15**（`node:zlib` 的 zstd API 从该版本开始提供）；`engines` 与 README 已同步。

## 公开面

- 移除 `docs/PUSH-TO-GITHUB.md`、`docs/PARITY-REPORT.md`；
- `lib/ingest/CONFIG-NOTES.md` 改写为用户配置文档 `docs/configuration.md`；
- README 安全说明与实际一致：记忆默认本机；远端 LLM / embedding / 重排仅在配置后使用；控制台密钥保存在本机且不回显；
- 安装步骤补真实仓库 URL、cordis 接线说明与 LLM 前置条件；
- `package.json` 的 `files` 收紧为运行时必需文件，并补 `repository` / `homepage` / `bugs`。

## 目录与测试

- 45 个 `selftest*.mjs` 迁入 `tests/`；
- 测试发现器同时扫描 `tests/`，并拒绝「0 套全绿」；
- 变异测试区分「测试失败」与「模块加载/语法错误」；
- 同步 `restart-batch`、`final-acceptance`、`audit-negative-tests`、`snapshot-code` 的套件路径与扫描范围。

## 发布门禁

- 新增 `.github/workflows/check.yml`：push / PR 跑 `npm run check` 与陌生人全量；
- `release.yml` 先校验标签、包版本、版本说明，再执行 `npm run check:release`；
- 新增 `check-package`：检查真实 tarball 必需文件在、内部文档/测试/脚本不在；
- `js-yaml` 作为显式测试依赖，CI 缺依赖直接失败。

## 验证

- `npm run check:release` ✅（含 45 套陌生人全量、audit、打包检查）；
- 从 GitHub 重新 clone 验收：45 套全绿 / pass=11 fail=0。

## 升级

覆盖 `lib/`、`client.js`、`cordis.patch.yml`，重启 DSH。无运行时行为变更，无需改配置。
