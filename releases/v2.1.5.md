# v2.1.5 — 2026-11-16

功能版（默认关闭），新增可选的「详情档分配策略」。

## 背景

L0 注入里只有 `detailTop` 张卡能拿到 full/summary，其余只有标题。原实现固定按 `createdAt` 新→旧选，导致「最近但未必最相关」的卡拿全文。

## 改动

- `workingMemory.recency.detailPolicy` 新增三个取值：
  - `recency`（默认）：原行为，逐字节不变；
  - `relevance`：按 `finalScore` 降序取前 N，严格全序（分数相同按候选顺序、再按 `cardId`）；
  - `hybrid`：`finalScore` 第 1 名拿 full，剩余名额按 recency 补；全缺时间戳时按相关性补满。
- 非法值回落 `recency`，并记 `wm-detail-policy-unknown` 日志。

## 验证

- `selftest-p4` 新增 J 组 8 条全部通过；
- 全量 `npm run check:release` 通过（含陌生人环境测试、安全审计与数据泄露终检）。

## 升级

覆盖 `lib/`，重启 DSH 即可。默认配置下行为与升级前一致，无需改配置。
