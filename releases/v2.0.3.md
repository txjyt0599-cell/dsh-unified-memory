# v2.0.3 — 2026-11-09

小版本，两处修复，没有破坏性改动。

## 修复

### 1. 读侧标题兜底（超图 / 卡片标题）

`finalizeTitle` 原来只做「清洗 → 提炼」两步。实测有卡片两步都过不了 `isGoodTitle`，于是「（无标题）」「但它能成立」这种半句标题一直漏到检索层。

现在补第三步：**若仍不合格且正文含中文，取正文首句**（去掉 `【…】` / `[…] ` 类前缀，截 24 字），合格才采用。

- 只取原文片段，**不生成、不补写** —— 宁可继续红着，也不伪造标题。
- 位置在读侧出口，三条写卡路径（启发式 / LLM / 兜底）一次覆盖。

### 2. 日记根目录脏值回退

`PM_DIARY_ROOT` 从进程环境继承时可能被上游用 GBK 解码，出现 `D:\...\鏃ヨ` 这类乱码路径。旧实现直接采信 ⇒ 日记后端 `health()` 返回 `not-found`，`diary_write` 全挂。

现在：**路径存在才采信**；不存在则按原优先级回退到 `PM_WORKSPACE/日记`，再不行落到数据目录 `diary/`。任何机器上都不会因为一条脏环境变量把日记功能废掉。
