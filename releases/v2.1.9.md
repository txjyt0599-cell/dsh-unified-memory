# v2.1.9 — 2026-11-19

生产端 / 发布端功能对照的收尾修复版。v2.1.8 已补齐 continuity 底层引擎；本版修掉对照中发现的 3 个非接口型差异。

## 修复

- `diary/scheduler.js` 补回 `once: true` 持久认领与 `acquireLock()` 跨进程锁，避免冷重启后重复 nudge。
- `section.js` 补回 `createSectionProbeWriter` 的 8 MiB 轮转，长时间运行不再让 section 探针无限增长。

## 对照结论

- `endpoint-config.js` 保留开源版原有 write-only API Key 能力，不随生产版覆盖。

- `lib/` 文件集 **103/103 完全对应**，无缺失模块。
- 归一化脱敏后，continuity 关键文件（index / prefetch / prefetch-continuity / inject-fingerprint / working-memory / retriever / bm25 / stages / alias / index-store / graph / l0-rounds / budget / log）无功能差异。
- 剩余差异均为**有意开源适配**：开箱默认写入链为 true（生产默认 false）、空场景根 / 空 hostAxioms、LLM 启动告警与配置模板、私有领域词替换、ledger schema 中性命名、控制台额外 write-only API Key。
- 陌生人全量 **60 套全绿 / pass=11 fail=0**；`npm run check:release` 全链 exit 0。
