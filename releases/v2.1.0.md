# v2.1.0 — 2026-11-09

**这个版本把「配置要改文件」这件事彻底改掉了** —— 插件自带图形控制台，装好就能在 DSH 里点着配。

## 新增

### 1. 内置图形控制台

- 位置：DSH 侧栏 **「记忆中枢」**，或 **设置 → 记忆中枢**。
- 四个页面：
  - **运行总览**：卡数、索引（模型 / 维度 / 兼容性）、四条线路就绪情况、遥测占比
  - **记忆管线**：开关与数值滑块集中管理（热配置，保存即生效）
  - **模型线路**：L1 语义炼成 / E1 向量主路 / E2 本地备路 / R1 本地精排
  - **运行遥测**：各档位注入次数、延迟、降级原因

### 2. 模型线路可视化配置

每条线路可直接改 **Base URL、模型名、向量维度、超时、启停**，不需要碰 JSON。

- **测试连接**：真实发起 `/embeddings` 或 `/chat/completions`；向量线路会校验返回维度与现有索引是否兼容。
- **恢复配置继承**：清掉某条线路的页面覆盖值，回到 `config.json` / DSH profile 的配置。
- 保存后标记 **待重启**，不会在运行中途静默切换线路。

### 3. API Key 写入（write-only）

页面提供密钥输入框，规则：

- 填了就写入本机 `$PM_DATA_ROOT/ingest/model-endpoints.json`，文件权限 `600`；
- **永不回显**：状态接口不返回、浏览器包不内置；
- **留空 = 保持原样**，不会误清空既有密钥；
- 密钥不经过任何第三方服务。

## 适用环境

控制台依赖 DSH Web 档的 `webServer`。headless 环境（无 Web 服务）会自动跳过挂载，记忆主功能不受影响，此时仍可改配置文件。
