# v2.1.1 — 2026-11-10

补丁版，修控制台一个会让配置「假保存」的接线缺陷。

## 问题

在控制台里填了 API Key / Base URL 保存后，页面提示「待重启」；**重启 DSH 后提示仍然挂着，怎么都消不掉**，而且新配置其实也没生效。

## 根因

开源版 `lib/index.js` 的启动流程漏了一行：

```js
c = applyEndpointOverrides(c);
```

后果有两层：

1. **保存的地址 / 模型 / 密钥从未合并进运行配置** —— 控制台只是把值写进了 `model-endpoints.json`，插件启动时根本没读；
2. 覆盖配置的**指纹从未写回** `config.__endpointOverridesFingerprint` ⇒ `hasPendingEndpointRestart()` 永远返回 true ⇒ 「待重启」徽标永远消不掉。

## 修复

`lib/index.js` 在配置合并后、挂载控制台前补上：

```js
c = applyEndpointOverrides(c);
__lastGoodConfig = c;
```

现在：保存 → 提示「待重启」→ 重启 DSH → 配置生效且徽标消失。

## 回归

- `selftest-dashboard` 新增静态接线断言：`index.js` 必须包含 `c = applyEndpointOverrides(c)`。缺行即红，防止再次漏接线。
- 单元断言：`applyEndpointOverrides(config)` 后 `hasPendingEndpointRestart() === false`。

## 升级

覆盖 `lib/`，重启 DSH。之前已经保存过但没生效的端点配置，会在重启后自动生效。
